# Marketplace listing

Set up listings that get found and sell. Work fast: this is simple work, so don't over-research. Draft first; Nick publishes, or says yes before anything goes live.

- Facebook Marketplace: Nick Graham's personal profile. No shipping option on his account, so postage goes in the description.

## Facts

1. Identify the exact model from the photos (labels, model numbers, port markings), then check a manufacturer or primary retailer spec.
2. State conditional claims plainly and briefly, without technical caveats or confidence levels in the listing. Approved wording: 'Monitors: two external monitors on any laptop through the two numbered outputs (each HDMI or DisplayPort), which may need a one-off free driver install. A third monitor works through the HDMI port marked DP Alt Mode, if your laptop's USB-C port supports DisplayPort Alt Mode.'
3. Collect: colour, dimensions (L x W x H cm), material, model, MPN, every port, what is included. If dimensions are not published, ask Nick to measure; never estimate.
4. Ask Nick about accessories he can add (spare cables, chargers) and mention them.

## Only what helps the sale

- Never mention marks, scuffs, wear or minor faults unless Nick approves the wording. Default condition line: 'Fully working.' plus what is included.
- No detail that adds doubt or friction: no hedges, no chipset speculation, no 'I think'.
- Don't duplicate in the description what a structured field already shows (colour, size, brand, dimensions, condition).
- Do not claim 'fully working' for an item Nick reports as faulty or untested.
- Watch for auto-filled fields (eBay can set Country of Origin itself); keep only what is correct.

## Titles (search-led)

Buyers search for what the thing is, not for an unknown brand. Order:

1. Generic product type buyers type: 'USB-C Laptop Docking Station', 'USB-C Hub Multiport Adapter'
2. Key specs that filter searches: ports, wattage, resolution, size, capacity
3. Brand and model last
4. Inclusions if space: '+ PSU', '+ 2 Cables'

eBay max 80 characters; check the count before typing. No all caps, symbols or filler. Facebook shows roughly the first 40 characters in the grid, so front-load the product type. Use the same leading terms on every platform.

## Structured fields (fill every one you can)

- eBay item specifics: Brand, Type, Model, MPN, Colour, Ports (tick every port; search the box for ones not in the first list, such as Ethernet), Material, Item Length / Width / Height, Compatible Brand. Use eBay's suggestions only where correct.
- Facebook: title, price, category (Electronics & computers), condition, Brand, Colour, Size.
- Vinted: category, brand, condition, colour, size, parcel size.

## Description template (short)

1. What it is: brand, model, type (nothing a field already shows)
2. What it does, with conditions stated plainly
3. Ports / features as one list sentence
4. What is included, and anything the buyer must supply
5. 'Collection from Sydenham SE26, or tracked postage for £X' (price on Facebook)

British English, no em dashes, no hype.

## Photos

- Convert iPhone HEIC to JPEG (eBay rejects HEIC). Apply EXIF orientation, then check every image and rotate so text on the product reads the right way up.
- Light enhancement only: autocontrast, slight brightness and sharpening. Never hide defects.
- Name files in upload order: '<Item> 1 front.jpg' and so on. Lead photo: whole item, front.
- Save to Personal Admin/Outputs/'<Item> Sale - Listing Photos - YYYY MMM DD' on Nick's Mac, stage them, then upload from the staged path.

## Pricing

- Check eBay sold listings (last 90 days) and the 'Sold listings' panel in the eBay form. Treat undated asking prices as weak evidence.
- Buy It Now with offers on and a minimum offer near the realistic floor.
- Facebook can sit slightly above eBay (no postage for local buyers).

## Postage

- eBay: Simple Delivery, buyer pays. Choose the parcel size honestly (include power bricks in the weight).
- Facebook: tracked postage price in the description.
- Vinted: built-in shipping, buyer pays.

## Browser gotchas

- eBay's description editor sometimes saves blank. Reopen each draft after saving and confirm the text is there.
- Pressing cmd+A before the editor has focus selects the whole page. Click inside the existing text first.
- Facebook ignores scripted clicks on confirm buttons; use real clicks.
- If Nick has a draft open in another tab, don't edit that draft at the same time.
