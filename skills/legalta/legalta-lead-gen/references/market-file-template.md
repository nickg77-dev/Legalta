# Market file template (one per country, saved in Drive, not in the skill)

Title: "[Country] - Legalta Market File - YYYY MMM DD"

1. Brief: country, segments in scope, language, owner, status, go / no-go date.
2. Sizing: Thomas's figures first, then any deeper figures, each with source and date.
3. Saturation: claim vehicles, collective actions, court cases, associations already organised; level per segment (High / Medium / Low / Unknown).
4. Data scraping potential: Market Scoring rating, best list source, gaps, research prompt run date.
5. Sources used: Data Sources rows used, with method and date.
6. Intermediaries: associations, dealers, fairs, with status.
7. Results: leads added, qualified, contacted, replies, already-claimed share (per company), decisions.
8. Open questions for Thomas or MMG.
