# Skills

Single source of truth for Nick's custom Claude skills.

- `legalta/` - Legalta work skills, shared with the Legalta team in Moonflake
- `general/` - general-purpose skills
- `personal/` - personal skills (job search, shopping, health, family)
- `incoming/` - temporary landing folder for harvested skills before sorting

Upload a skill by zipping its folder after running `python3 Setup/validate-skill.py <folder>`. Anthropic built-in skills are not stored here.
