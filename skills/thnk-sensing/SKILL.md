# THNK Sensing

Guide a disciplined, divergent exploration of a problem, then converge on a Creative Question that opens a rich solution space. Based on the THNK Innovation Flow Toolkit (Sensing phase, tools 1-23).

## Core principle

Sensing is the pursuit of serendipity: looking for insights you do not yet know you need. It is deliberately inefficient. Resist solutioning. If Nick proposes solutions during Sensing, park them in an "idea fridge" and return to exploration.

## Process

### Step 1: Frame the expedition (5 min)
Ask, in one short message:
- What is the challenge, in Nick's own words?
- How much time is available (2 hours, 2 days, 2 weeks)?
- Solo or with a team?
- What does Nick already believe is true about this problem? (These beliefs become reframing targets later.)

### Step 2: Select 2-3 divergent tools
Never suggest more than 3. Match to need:

| Need | Tool | What it does |
|---|---|---|
| Personal connection to topic | Passion & Purpose | Divine discontent + golden opportunity |
| Ground truth data | Facts and Figures | Hard numbers on the problem space |
| Understand the user | User Interviews, Empathy Map, User Journey | Latent needs, pains, moments that matter |
| Fresh stimulus | Wild Safari | Field visits to analogous or extreme settings |
| Expert input | Expert Interviews | Contrarian and insider perspectives |
| System dynamics | Force Fields, Stakeholder Engagement | Drivers, blockers, power and incentives |
| Challenge assumptions | Reframing | Overturn core beliefs and supporting beliefs |

Time-constrained default (under 1 day): Facts and Figures + 3 user conversations + Reframing.

### Step 3: Run the tools
For each selected tool give: purpose in one line, step-by-step pointers (max 6 steps), a capture template (table or canvas Nick can copy into a Google Doc or Sheet), and a time budget.

### Step 4: Converge
Use in sequence:
1. Mining for Gold - each insight written as a surprising, specific statement (not a category)
2. Connecting the Dots - cluster insights, name the clusters
3. Creative Question - one question that begs to be answered

### Creative Question quality bar
A good Creative Question is:
- Open ("How might we...") not binary
- Specific enough to exclude obvious answers
- Broad enough to allow many solution directions
- Rooted in at least one surprising insight from Sensing

Weak: "How might we make a better seasonal produce calendar?"
Strong: "How might we make eating seasonally the path of least resistance for a parent whose child rejects most vegetables?"

## Output format
Always end a Sensing session with a plain-text summary block Nick can paste into a doc:
- CHALLENGE (1 line)
- TOP 5 INSIGHTS (each 1 sentence, surprising and specific)
- BELIEFS OVERTURNED (2-3)
- CREATIVE QUESTION (1)
- CONFIDENCE that this question opens a rich solution space (%, with the biggest unknown named)

## Never do
- Never generate solution ideas during Sensing (park them instead)
- Never suggest more than 3 tools at once
- Never accept a Creative Question containing a solution ("How might we build an app that...")
- Never present generic insights ("users want convenience") - every insight must be falsifiable and specific
- Never skip Step 1 context questions
